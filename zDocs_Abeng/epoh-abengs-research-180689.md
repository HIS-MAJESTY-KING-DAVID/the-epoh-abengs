## 10. Website Strategy

### Concept: "A Beautiful Life, Together"

A bilingual (FR/EN) lifestyle website — part blog, part portfolio, part community hub — extending their viral social media presence into a professional brand home.

### Site Map

| Page                         | Description                                                                                                                 |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Home**               | Dynamic hero with top-performing Reels/videos, bilingual mission statement, latest blog highlights, CTA to follow/subscribe |
| **About Us**           | Origin story, individual backgrounds, mission behind the content, relationship timeline                                     |
| **Le Blog / The Blog** | Categories: Marriage, Beauty, Recipes, Faith                                                                                |
| **Gallery**            | Curated visual portfolio of best lifestyle photography + video embeds                                                       |
| **Collaborations**     | Media kit download, past partnerships showcase, brand inquiry form                                                          |
| **Contact**            | Integrated form + direct links to all 5 social platforms (YouTube, TikTok, FB, Instagram, Threads)                          |

### Design Direction

* **Vibe** : Warm, inviting, "Modern African Elegance"
* **Palette** : Earthy tones (terracotta, cream) + gold accents
* **Typography** : Elegant serif headings + clean sans-serif body
* **Imagery** : Full-bleed couple/family photos, candid lifestyle shots
* **Key feature** : Prominent FR/EN bilingual toggle in navbar
* **Video-first** : Embed top Reels/YouTube content on Home and throughout

### Tech Stack

* **Next.js** + **TailwindCSS** — Fast, SEO-friendly, built-in i18n for bilingual
* **UI UX Pro Max** skill — AI design intelligence (see section 6 below)
* **Headless CMS** (Sanity or Contentful) — Client can manage blog posts
* **Netlify / Vercel** — Deployment
* Alternative: WordPress if client prefers full self-management

## 11. UI UX Pro Max — Design Intelligence Layer

 **What it is** : An AI skill ([GitHub](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)) that provides design intelligence for building professional UI/UX. It auto-generates a complete design system and enforces best practices during code generation.

 **Why use it** : Instead of manually picking styles, palettes, and fonts, the skill will automatically reason about the best design system for a Cameroonian lifestyle/couple brand and generate it.

### How it will work

1. **Install** the skill in the project
2. **Auto-activates** when we start building UI — just chat naturally ("Build the home page for The Epoh Abengs")
3. **Design system generated** — AI picks optimal UI style, color palette, font pairing based on the lifestyle/family niche
4. **Code output** — Implements Next.js + TailwindCSS components with proper colors, fonts, spacing, and accessibility
5. **Pre-delivery checks** — Validates against common UI/UX anti-patterns
