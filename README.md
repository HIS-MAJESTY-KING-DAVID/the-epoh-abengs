# The Epoh Abengs Website

A bilingual (French/English) lifestyle website for The Epoh Abengs — a Cameroonian couple brand focused on marriage, family, beauty, and godly counsel.

## About

The Epoh Abengs is a faith-centered couple brand sharing authentic content about:
- Marriage & Couple Life
- Beauty & Self-care
- Recipes & Home
- Faith & Inspiration

**Social Media**: [YouTube](https://youtube.com/@the_epohabengs) | [TikTok](https://www.tiktok.com/@the_epohabengs) | [Facebook](https://www.facebook.com/share/18UFB3i3dP/?mibextid=wwXIfr) | [Instagram](https://www.instagram.com/the_epohabengs) | [Threads](https://www.threads.com/@the_epohabengs)

## Tech Stack

- **Framework**: Next.js 16.2.4 (App Router)
- **Styling**: TailwindCSS 4.2.0
- **UI Components**: Radix UI + shadcn/ui
- **Language**: TypeScript
- **Package Manager**: pnpm

## Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm

### Installation

```bash
# Install dependencies
pnpm install
```

### Development

```bash
# Run development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
# Create production build
pnpm build

# Start production server
pnpm start
```
